Waypoints for classic "et_base" gameplay. No support for "brewdog" gameplay.

For "mapscript with ladder near Axis spawn" waypoints you need to enable ladder in mapscript.

Optional settings that will work with "mapscript with ladder near Axis spawn" and "default mapscript":
-upper route at main tunnel towards North Radar
-corridor connecting documents bunker to South Radar
-connection between upper 1st Allied spawn, catwalk towards upper offices/CP
-side passage next to tunnel gate (bots won't use it)
